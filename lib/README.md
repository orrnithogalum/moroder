# Discord SDK

This directory is expected to contain the **Discord Social SDK**.

Please download or obtain the Discord SDK and place its contents under:

```text
lib/discord_social_sdk/
├── include/
│   ├── cdiscord.h
│   └── discordpp.h
├── lib/
│   └── release/
│       └── libdiscord_partner_sdk.so
└── License-Notices.txt
```

The project expects the SDK headers and library to be available at these locations. Make sure the folder structure matches the example above before building.
